# Project guide for Claude

This repo holds market research, Instagram content matrices and content plans for a UAE content & growth marketing agency.

## Structure
- `research/`: one market research file per target segment (00 = overview)
- `content-matrix/`: Instagram signal-ladder framework (00) plus a 10-post matrix per segment
- `content-plan/`: finished reel and carousel scripts
- `brand/brand-guide.md`: **brand colours, gradients and contrast rules**

## Always do this when generating content ideas, scripts or visuals
1. **Include visual colour direction for every idea, reel, carousel slide or story**, using `brand/brand-guide.md`:
   - Background: Night Depth gradient (`#0a1a30 → #16304e → #2a517f`) by default
   - Text: white (`#ffffff`)
   - Accent (key number, key word, progress marker, icons): Steel Teal `#6896a3`
   - CTA buttons/tiles: Tide gradient (`#2a517f → #6896a3`) with `#0a1a30` text
   - Ratio: ~70% navy gradient / ~20% white / ~10% teal
2. **Never put small white text on `#6896a3`** (3.2:1 contrast). Large bold headlines only.
3. Don't use red or other off-brand colours for "wrong" states. Use white at 40% opacity with a teal strike-through.
4. Hook visual and hook text must say the same thing. The body is one simple sentence plus one visual per line.
5. Tag each piece with its signal-ladder level (Share / Save / Watch / Profile / Convert). See `content-matrix/00-framework.md`.
6. Label illustrative numbers as examples. Never present invented results as real client results.
